SB Assistant

Mac app · Bangla voice assistant

A personal voice assistant that speaks Bangla and runs only on your own Mac. It plans your exam study, quizzes you from your notes, reminds you of Classroom deadlines, controls the Mac and works in Safari. Anything that sends, posts or deletes waits for your “yes”. Free and open source.

Built into the code

It asks first

These are rules in the code, not just instructions to the AI, so a web page or an email can't talk it out of them.

Your yes, every time

Mail, file moves, deletes and risky buttons in Safari wait for an on-screen button or a spoken “yes”.

Pages are only data

Text from websites, mail and files is read as information, never followed as an instruction.

No passwords, no logins

It never types passwords or card numbers, never logs in for you, and never reads your personal social feed.

Read-only files

It only looks inside Desktop, Documents and Downloads, and changes nothing unless you approve.

Only on your Mac

The server listens on your Mac alone. Other websites can't reach it.

Keys stay private

Keys live in a private folder outside the code and are never uploaded anywhere.

Mac · about 15 minutes

Install on your Mac

You need a Mac and a Claude subscription. SB uses your own Claude Code login as its brain, so there's no AI bill to set up. Voice needs a free ElevenLabs account.

  1. Download SBClick “Download ZIP” at the top of this page. Double-click the file in Downloads to unzip it. You get a folder called SB-Assistant-main.
  2. Install Node.jsDownload the LTS version from nodejs.org and install it. To check, open Terminal (Cmd + Space, type Terminal) and paste this. You should see a version number.
    node -v
  3. Install Claude Code and sign inInstall the Claude desktop app or Claude Code, then sign in with your Claude account once. SB talks to it on your Mac.
  4. Start SBPaste this in Terminal and keep the window open. Then open http://localhost:3000 in Safari.
    cd ~/Downloads/SB-Assistant-main && node server.js
  5. Add your voice keyOpen http://localhost:3000/setup.html, paste your ElevenLabs API key and pick a voice. The key is saved only on your Mac.
  6. Give it permissionOn SB's page, open Settings and click “সব অনুমতি চাও”. macOS asks one by one, so click Allow or OK for each.
  7. Optional: university mailTo read Classroom deadlines, add your college email to SB's settings file as MAIL_FROM. It must already be set up in the Mac Mail app.
    open -e ~/Library/Application\ Support/SB/.env

Stuck?

If something goes wrong

“Claude Code খুঁজে পাইনি”

SB can't find Claude Code. Install it and sign in, then start SB again.

The mic doesn't work

System Settings → Privacy & Security → Microphone, then turn on Safari. You also need the ElevenLabs key from step 5.

Safari or Mail jobs fail

Click “সব অনুমতি চাও” in Settings again. Then check System Settings → Privacy & Security → Automation.
