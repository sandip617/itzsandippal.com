Free · about 5 minutes

Run it free on GitHub Pages

You only need a free GitHub account. The board won't update by itself, but you can post a new edition any time.

  1. Fork the codeOpen github.com/sandip617/news-board and click Fork (top right), then Create fork. You now have your own copy.
  2. Turn on GitHub PagesIn your fork, go to Settings → Pages. Under Branch pick “main” and “/ (root)”, then click Save.
  3. Open your boardWait about a minute, then refresh the Pages settings. Your link appears at the top. It looks like this:
    https://YOUR-USERNAME.github.io/news-board/
  4. Post a new editionIn your fork, open the data/days folder. Copy the newest file, name it with today's date (like 2026-11-04.json) and change the news, blog and quiz. Then open data/index.json, add the new date at the top of the list and set “latest” to it. Click Commit changes, and your board updates in about a minute.

Make it update by itself

  1. Download the codeOpen this ZIP link. Double-click the file in Downloads to unzip it. You get a folder called news-board-main.
  2. Install Claude CodeFollow the steps at claude.com/claude-code and sign in with your Claude account. The desktop app or the VS Code extension are the easiest.
  3. Open the folderIn Claude Code, open the news-board-main folder you just unzipped.
  4. Publish your boardPaste this into Claude. It puts your board online on claude.ai and gives you a link that starts with https://claude.ai/artifact/. Copy that link.
    Follow Step 1 in SETUP_WITH_CLAUDE.md in this folder: publish index.html and the data folder as a new Artifact with the capabilities listed there, then give me the link.
  5. Create the daily updatePaste this, with your link in place of the example. Claude adds your link to the instructions and sets up a “routine” that runs at 6:45 AM India time, so the new edition is ready by 7.
    In ROUTINE_PROMPT.md, replace YOUR_ARTIFACT_URL with https://claude.ai/artifact/PASTE-YOUR-LINK. Then follow Step 2 in SETUP_WITH_CLAUDE.md to create the daily routine.

Stuck?

If something goes wrong

The board says today's edition hasn't arrived

The data files didn't publish. On GitHub Pages, check that data/index.json lists a date that has a matching file in data/days. With Claude, open claude.ai/code/routines, click the latest run and read what it says.

The routine ran but nothing changed

Check that ROUTINE_PROMPT.md has your own link, not YOUR_ARTIFACT_URL. Then ask Claude to update the routine with the new file.

Friends can't open the board

A new board on claude.ai is private. Open it, click Share and change who has access.

The topic suggestion box is missing

It only works on claude.ai, because suggestions are saved in a shared database there. On GitHub Pages it's hidden.
