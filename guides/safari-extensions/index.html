Turn on a Safari extension

Safari keeps extensions you install yourself switched off until you allow them. Follow these steps once. Tick each step as you go.

Restarted Safari and the extension disappeared?

That’s normal. Safari switches off “Allow unsigned extensions” every time you quit it (⌘Q) or restart your Mac. Do step 3 again: it takes 10 seconds, and your settings are kept. Or sign it once so it stays on for good.

If NN Tab ever disappears from the Extensions list, do steps 2 and 3, then run NN Tab’s build command again.

Optional · free · about 15 minutes

Keep it on after a restart

Safari switches off unsigned extensions whenever it quits. Sign YT Premium Vibe once with your own free Apple ID and Safari treats it as signed: it stays on after every restart, and you never need “Allow unsigned extensions” again.

  1. Install XcodeGet Xcode free from the Mac App Store. Open it once and let it finish installing its extra parts.
  2. Sign in and create a certificateXcode → Settings → Accounts → + → Apple ID. A free Apple ID is enough. Select your team, click Manage Certificates, then + → Apple Development.
  3. Point Terminal to XcodeOpen Terminal (⌘ + Space, type Terminal), paste this, and enter your Mac password:
    sudo xcode-select -s /Applications/Xcode.app
  4. Download the source codeClick the button, then double-click the file in Downloads to unzip it. You get a folder called YT-Premium-Vibe-Extension-main. Download source ZIP ↓
  5. Build & install the signed appPaste this in Terminal. It signs the app with your certificate, replaces the old one in Applications and opens it. Wait for “✓ Installed” (a few minutes the first time).
    cd ~/Downloads/YT-Premium-Vibe-Extension-main && bash install-on-my-mac.sh
  6. Turn it on one last timeSafari sees the signed app as new. Do step 4 (tick it in Extensions) and step 5 (allow youtube.com) again. Then you can untick “Allow unsigned extensions”.
✓ Done. Restart your Mac as often as you like. YT Premium Vibe stays on.

Nothing to do. NN Tab is already signed with your own Apple ID when you build it with its install command, so Safari keeps it on after every restart.

Still stuck?

The extension isn’t in the Extensions list

Open the extension’s app from your Applications folder once, then check step 3.

I can’t find the Developer tab

Do step 2 first. The Developer tab only appears after “Show features for web developers” is ticked.

Nothing changed on the website

Reload the page after step 5. You can check access anytime in Safari → Settings → Websites → Extensions.
